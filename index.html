    ℹ️ 关于本项目

    v0.1.0

    MintCoach（薄荷教练）是一个多智能体健身应用：填写信息生成训练与营养方案，训练时实时评测姿势并语音报数， 训练后可打卡复盘、记录饮食。

    团队名称：彰理峰高

    👥 成员分工

    Roles
    • 产品与交互需求拆解、页面结构与交互流程设计
    • 训练与营养训练计划生成、营养方案与食物营养库
    • 姿势评测MediaPipe Pose 接入、动作计数与语音纠错
    • 前端与体验页面渲染、移动端适配、本地存储与测试文档

    🧭 使用说明

    Guide
    1. 填写信息：在首页填写目标、身高体重、每周训练天数、器械与伤病情况。
    2. 生成计划：点击「生成我的方案」，总控 Agent 会调度训练与营养 Agent。
    3. 开始训练：进入「训练模式」，选择自由训练或计划训练，打开摄像头开始评测。
    4. 记录饮食：在「打卡复盘」页搜索食物、填写分量，保存当天饮食记录。
    5. 查看复盘：完成打卡后，复盘 Agent 会给出报告与次日强度建议。

    启动方式：node server.js，浏览器访问 http://localhost:8000。
